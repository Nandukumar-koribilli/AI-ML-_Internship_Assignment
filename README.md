## ⚠️ Important: Setup & Authentication

For security reasons, sensitive API keys and credentials have been excluded from this repository (via `.gitignore`). **You must add the credential files provided via Email / Google Drive link to run the applications.**

### 1️⃣ Setting up Task 1 (Text-to-Speech)

The TTS application requires Google Cloud credentials to function.

- **File Needed:** `credentials.json`
- **Action:**
  1.  Download `credentials.json` from the provided Google Drive link/Email.
  2.  Place it inside the **`Task - 1`** folder.
  3.  Run the app:
      ```bash
      cd "Task - 1"
      streamlit run app.py
      ```

### 2️⃣ Setting up Task 2 (AI API Integration)

The AI API integration task requires an environment file with API keys.

- **File Needed:** `.env`
- **Action:**
  1.  Download the `.env` file from the provided Google Drive link/Email.
  2.  Place it inside the **`Task - 2`** folder.
  3.  Run the CLI app:
      ```bash
      cd "Task - 2"
      python cli_app.py
      ```
  4.  Or run the Web app:
      ```bash
      cd "Task - 2"
      python web_app.py
      ```
